# Boutique des Français Volants

A free order page for club merchandise. Parents pick products, sizes and quantities for each child and submit. Each order gets a number and the parent receives a confirmation email. Payment happens separately, through the club's payment link.

```
Static page (GitHub Pages)  --text/plain JSON-->  Apps Script web app  -->  Google Sheet
```

- `index.html`, `style.css`, `js/`: the page. Vanilla ES modules, no build step.
- `config.js`: the Apps Script web app URL.
- `apps-script/Code.gs`: the whole backend (catalogue, order validation and pricing, numbering, email, `setupSheet`).
- `fixtures/catalogue.json`: demo catalogue, generated by `npm run fixture`.

## Develop

```sh
npm test        # node --test: cart logic + Code.gs in a vm with fake Google services
npm run dev     # http://localhost:8000/?demo, demo mode with no backend
npm run fixture # regenerate the demo catalogue after changing the seed in Code.gs
```

Node ≥ 22. There are no npm dependencies.

## Rules worth knowing

- The server recomputes every price from the Sheet and ignores prices sent by the browser.
- User text written to the Sheet is prefixed with `'` (`text_()`), so it can't become a formula.
- `clientId` makes resubmits idempotent. A new id is generated only after a successful order.
- Keep `Code.gs` plain Apps Script: no modules. The tests call its top-level functions.
